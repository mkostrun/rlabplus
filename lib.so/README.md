<p dir="auto"><strong><em>RLaB3</em></strong> is an interactive, interpreted scientific programming environment for Linux operating system.
It allows fast prototyping and script development.
Its syntax is a combination of c (curly brackets for blocks of statement, some statements) and M**LAB and fortran (e.g., indexing of arrays starts from 1).
The project
<a href="https://sourceforge.net/projects/rlabplus" rel="nofollow"><strong><em>RLaB3</em></strong></a>
provides a syntax update with some internal and organizational changes compared to
<a href="https://rlab.sourceforge.net" rel="nofollow"><strong><em>RLaB2</em></strong></a>, as developed by Ian Searle.
The projects support 32- and 64-bit linux systems, for AMD, Intel and arm/RaspberryPi.</p>
<p dir="auto">The project <strong><em>RLABPLUS</em></strong> adds a number of solvers, input/output operations, and visualization features and connections to other specialized software,
in form of shared object libraries.
Basically, the solvers within the project are aimed at narrow technical field, and might not be of interest to wide audiences.
For that reason, these solvers were not incorporated into <strong><em>RLaB3</em></strong> but are, so to speak, free standing.</p>
<p dir="auto">The project comprise the following solver libraries:</p>
<ul dir="auto">
<li>
<p dir="auto"><em>gpib</em> - GPIB (Hewlett-Packard's General Purpose Interface Bus, for those who still use it and remember it)
for hardware and instrumentation control: <strong><em>RLaB2</em></strong>/<strong><em>RLaB3</em></strong> wrapper for <a href="https://sourceforge.net/projects/linux-gpib" rel="nofollow">linux-gpib</a>.</p>
</li>
<li>
<p dir="auto"><em>glpk</em> - provides solvers from <a href="https://www.gnu.org/software/glpk" rel="nofollow">GNU linear programming kit</a>.</p>
</li>
<li>
<p dir="auto"><em>gphoto2</em> - provides camera control and image download for usb connected cameras using <a href="http://gphoto.org" rel="nofollow">gphoto2</a>.</p>
</li>
<li>
<p dir="auto"><em>gts</em> - provides access to <a href="https://gts.sourceforge.net" rel="nofollow">GNU triangulation library</a> for meshes creations and computations.</p>
</li>
<li>
<p dir="auto"><em>kripto</em> - provides cryptography functions from <a href="https://github.com/LightBit/libkripto">libkripto</a>.</p>
</li>
<li>
<p dir="auto"><em>matio</em> - MATLAB /mostly input/only basic output/ library: if you are wondering about the asymmetry, well, since 2010's <strong><em>RLaB2</em></strong>/<strong><em>RLaB3</em></strong>
